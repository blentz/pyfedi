Fonts for the hacker_bbs themes, served from here so no page fetches from another host.
Every file is shipped exactly as its author released it: byte for byte, nothing converted, subset or renamed.
Six families (SIL Open Font License 1.1, each OFL.txt beside its file): the upstream TTF from
github.com/google/fonts @ e7db6ca603fd4862010383ff17ffd6cc4ffac1c0, ofl/<family>/. CrimsonPro[wght].ttf is the
upstream variable font.
ibm_vga/web_ibm_vga_8x16.woff: Ultimate Oldschool PC Font Pack by VileR, int10h.org, CC BY-SA 4.0
(see ibm_vga/LICENSE.txt).
tests/test_shipped_css_offsite.py holds each file's SHA-256.
